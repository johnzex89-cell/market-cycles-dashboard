# 市场周期看板

标普 500 的**牛熊周期 · 估值冷热 · 市场宽度**三层图，每天自动更新。

线上：https://johnzex89-cell.github.io/market-cycles-dashboard/

参考 Fidelity「Market Cycles」那张图的**结构**，但三层指标全部改用公开数据自建口径。
**不是复刻，也复刻不了** —— 原因见下面「为什么不能复刻」。

## 三层是什么

| 层 | 内容 | 数据源 | 覆盖 |
|---|---|---|---|
| 上层 | 牛熊周期柱，绿=牛市累计涨幅、红=熊市累计跌幅 | multpl（Shiller 月度价格） | 1961 至今 |
| 背景 | 估值色带，红=贵、蓝=便宜（**5 年** CAPE） | multpl 价格 + 盈利 + CPI，自算 | 1961 至今 |
| 下层 | 市场宽度代理：等权 − 市值加权 12 个月滚动收益差 | Kenneth French Data Library | 1961 至今 |

## 为什么不能复刻原图

1. **原图那 18 段牛熊是人工策展的**。它的熊市里有 -15%、-14%、-10%，没有统一阈值；
   而且用的是日内极值。实测：20% 阈值只切出 7 段、10% 切出 17 段但幅度系统性偏小。
   任何公开算法都还原不出那串数字，所以这里改用**可复算的规则**（月度反转 10% 确认转势）。
2. **原图第三层的真数据要花钱**。「% of index outperforming yoy」需要历史时点的成分股名单
   + 含已退市公司的股价。免费源拿不到退市公司（雷曼、安然、柯达查询全部 404），
   而 1961 年以来离开标普 500 的约有 700 家，只用今天的成分股回算＝只统计幸存者。
   付费源（Norgate Diamond 档，能回到 1950）约 $787.5/年，且「历史成分股覆盖到哪一年」
   官网未写明，下单前需先问客服。

## 已知限制

- **价格是月内日均价**，不是月末收盘或日内极值 —— 会削平峰谷。
  例：2020 年 COVID 在本口径下是 **-19%**，日线口径是 -34%。
  这是数据源的硬约束：日线源 Yahoo / Stooq / FRED 在本机与 GitHub Actions 上**实测全部不可达**
  （Yahoo 两端都 429、Stooq 返回挑战页、FRED 超时且因授权只有近 10 年）。
- **下层不是原图那个指标**，是收益差（百分点）不是股票个数比例，所以用了独立纵轴。
  它还是全市场口径（含小盘股），个别年份可能与原指标方向相反。
- 盈利数据比价格滞后一两个月，最新几个月没有 CAPE，**留白不外推**。
- 「每天更新」的实质：历史是月度数据，每天变的是**当前进行中那一段**（multpl 提供当日点位）。

## 快速开始

```bash
python3 scripts/fetch_data.py    # 抓 5 个数据源 → data/*.json（失败保留旧快照）
python3 scripts/build.py         # 算三层 → docs/data.json
python3 scripts/check_data.py    # 合理性自检，不过就该中止
cd docs && python3 -m http.server 8899   # 本地预览
```

只用标准库，无第三方依赖。

## 项目结构

```
scripts/fetch_data.py   抓取，只抓不算；任一源失败保留上次快照，不清空历史
scripts/build.py        计算三层，口径参数集中在文件顶部常量
scripts/check_data.py   上线前自检（7 类断言，已做 7/7 突变验证）
scripts/probe_sources.py  数据源可达性探测（手动触发，用来定源）
data/                   各数据源的原始快照，带 fetched_at 便于追溯
docs/                   GitHub Pages 目录（index.html + data.json）
```

## 自动更新

`.github/workflows/update.yml` 每天 UTC 12:00（北京时间 20:00）跑一次：
抓取 → 计算 → **自检不过就中止** → 提交。
